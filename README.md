# Hotel Maintenance Management System

> **A professional maintenance management system designed for hotel operations. The system manages maintenance requests, work orders, rooms, preventive maintenance, inventory, users, roles, and reporting.**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Render-brightgreen?style=for-the-badge&logo=render)](https://hotel-maintenance-system-mxai.onrender.com/)

---

## 📖 Project Description
The **Hotel Maintenance Management System** is an enterprise-grade web application built to streamline and automate facility maintenance operations across hotel departments. Designed for hotel managers, front desk staff, housekeeping, and maintenance engineers to eliminate manual logbooks and speed up request handling.

---

## ✨ Main Features
- 🛎️ **Maintenance Request Management**: Front office and housekeeping staff can submit issues with priority levels.
- 🛠️ **Work Order Lifecycle**: Assign work orders to technicians and track status (Pending, In Progress, Completed).
- 🏨 **Room & Asset Tracking**: Directory of guest rooms and physical assets (CCTV, HVAC, generators).
- 📦 **Inventory Control**: Track spare parts, reorder thresholds, and stock level alerts.
- 👤 **Role-Based Access Control**: Permissions for Admin, Manager, Technician, and Housekeeping.

---

## 🛠 Technology Stack
- **Backend**: Python, Flask, Flask-SQLAlchemy, Flask-Login
- **Database**: SQLite / PostgreSQL
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5
- **Deployment**: Render Cloud Hosting
